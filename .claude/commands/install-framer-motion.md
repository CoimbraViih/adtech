Instale o pacote framer-motion neste projeto Next.js.

Instruções:
1. Verifique se framer-motion já está listado em package.json (dependencies)
2. Se já estiver, confirme que está instalado em node_modules e rode `npm install` se necessário
3. Se não estiver, adicione ao package.json e rode `npm install`
4. Confirme a versão instalada com `npm list framer-motion`
